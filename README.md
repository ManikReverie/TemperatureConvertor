# Temperature Converter
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 8). It converts Celsius to Fahrenheit and Fahrenheit to Celsius.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Input field for temperature
- Two buttons: C to F and F to C
- Displays result with 2 decimal places
- Handles invalid input gracefully
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully converts temperatures between Celsius and Fahrenheit and displays the correct result.
